시작하기 전에 — Gemini API 키 등록

정답기가 사진 속 정답지를 읽어내려면 Google의 Gemini Vision API를 사용합니다. 이를 위해 무료 Gemini API 키가 필요하며, 키를 등록하기 전에는 채점용 정답지 업로드를 할 수 없습니다.

무료 키 발급 방법 (1분 소요)

  1. aistudio.google.com/apikey 접속 (Google 계정 로그인)
  2. "Create API key" 버튼 클릭
  3. 생성된 키를 복사
  4. 아래 입력란에 붙여넣고 저장
키는 이 기기에만 저장되며 외부로 전송되지 않습니다. 무료 쿼터만으로도 충분히 사용할 수 있습니다. 키가 유효하지 않으면 나중에 언제든 오른쪽 위 칩에서 다시 설정할 수 있어요.

텍스트 붙여넣기 경로는 키 없이도 사용할 수 있지만, 이 안내는 처음 한 번만 표시됩니다.
